## DiskLens 1.0

Первый релиз. Нативное приложение macOS для анализа диска и безопасной очистки,
заточенное под окружение разработчика.

### Что умеет

- **Обзор** — заполненность тома, сколько можно освободить
- **Папки** — обход дерева по размеру с drill-down
- **Очистка** — 16 категорий типового мусора с уровнями риска
- **Симуляторы** — устройства и рантаймы iOS через `simctl`; находит раздутый кэш клавиатуры,
  который у одного симулятора занимал 18 GB из 30
- **Docker** — образы, контейнеры, тома и кэш сборки через `docker` CLI: содержимое
  `Docker.raw` снаружи не видно, его знает только демон
- **Android** — AVD и пакеты SDK через `avdmanager` / `sdkmanager`
- **Инструменты** — индексы и кэши Xcode, SwiftPM, Flutter/fvm, Go, Rust, Gradle,
  npm, pip, Ollama, JetBrains, VS Code

### Безопасность

Там, где у инструмента есть своя команда очистки, используется она, а не `rm` — иначе
реестры инструментов рассыпаются (удалённая напрямую папка симулятора оставляет в Xcode
«призрака»). Всё остальное уходит в Корзину. Системные пути в чёрном списке.
Каждая находка помечена уровнем риска, «Выбрать безопасное» берёт только регенерируемое.

### Установка

Скачайте `DiskLens-1.0.dmg`, перетащите в «Программы». Приложение подписано ad-hoc,
поэтому при первом запуске: правый клик → «Открыть» → «Открыть», либо

```bash
xattr -dr com.apple.quarantine /Applications/DiskLens.app
```

Требуется macOS 14+.
